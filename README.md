Programa em python utilizando flask e docker funcional
demosntrando uma API de gerenciamento de controle de estoque

O projeto possui 5 containers docker

1 mysql (controle de produtos)
1 mongo (controle de estoque e movimentações)
1 api para o cadastro, alterações e listagem de produtos
1 api para o cadastro, alterações e listagem de estoque
1 api para o cadastro, alterações e listagem de movimentações
